Prerequisites:
- A modern web browser (Chrome, Firefox, Edge, or Safari)

Steps to run:
1) Download or extract project folder (3538_H446-03_Room_Booking_System)
2) Open index.html in your web browser (double-click the file or right-click and choose 'Open With' and then select your browser)
3) The Room Booking System Login Interface will appear
4) Use demo accounts to log in and test, or register a new account (admin must approve for the account to be used however)
5) After login all functionalities will be able to be used (based on role)

Additional Notes:
- If the page does not load correctly, ensure JavaScript is enabled in your browser.
- To clear all data, clear the localStorage for this page in your browser settings
- For Chrome: click More Tools and then Developer Tools and then select Application and Local Storage
